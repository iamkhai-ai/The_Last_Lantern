# The Shadow / Guardian — task 12 concept and prototype

Asset delivery only. No runtime, manifest, scenario or task-list changes. Sources: full approved scenarios 08, 09 and 10, tasks/plan.md task 12. Character proportions and quiet blue cloak follow existing pixel scenes; the Guardian is the same adult in a muted brown memory variant. His small blank head has no features. Identity remains concealed in the Level08 present silhouette.

Built-in imagegen created the retained character sheet and observatory scenery. `sources/prompts.json` preserves exact prompts and requested agent configuration (`gpt-6.1-sol`, `low`); runtime-resolved configuration and generator model are not exposed. Generated source dimensions and SHA256 are recorded in `asset-map.json`. `prepare_assets.py` performs deterministic crop, largest-component alpha cleanup, nearest reduction, fixed-canvas placement, opacity and composition. It does not claim the compositions are newly generated character art.

Character exports are 48×64 RGBA with shared foot pivot (24,62). Six native pose samples: waiting, shielding, calm right step, turn, back stillness and Guardian waiting. These are pose prototypes, not a complete looping animation. Alpha is binary on opaque pose frames; intentional uniform opacity is recorded for memory and dissolution frames. Character source specks outside the largest component are removed and transparent RGB is zero. No weapon, eye, fang, chase or attack details.

Memory previews use the shared foot at (174,231), with present Shadow → translucent Guardian → overlap → present Shadow. Guardian and present waiting share canvas/foot anchor but their generated shoulder contours differ slightly; blend rather than instant pixel substitution. The exact existing faded red scarf pixels are cropped from Level06 window at [68,64,85,99], with a red-dominance alpha mask removing surrounding stone, and separately placed by the window. Retained cloth RGB is unchanged. Lumo reuses `src/assets/lumo_0.png` directly on the spiral pipe plate. Guardian waits at the window; no daughter or outcome is shown. Level02 memory was inspected for style only and is not identified as this Guardian. No new narrative copy is embedded in the scene; production captions identify concept/prototype and state.

Level08 study places the faceless shielding pose at the seedlings with a white light fragment ending at his raised hand. Level09 after-memory/after-crystal study retains the Shadow. The Level10 dawn sequence is separate: stillness → two opacity reductions → faint afterimage → empty spot, with the same anchor and the wheel behind him. There is no disappearance on crystal pickup. The empty frame is intentionally transparent and is not a failed export.

All 640×360 studies and contact sheets are offline concepts. The scenery is a montage study of the observatory corner, not the Level09 three-room navigation layout. The generated dawn source may slightly change architectural pixels; integration should reuse fixed scenery geometry and animate actual wheel/lighting. No rain or birds are added. Forest trees beyond the window are scenery only.

Small pose detail is reduced at 1×; these samples need engine depth and animation evaluation before production approval.
