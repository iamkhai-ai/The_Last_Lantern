# Shared garden plant states

Produced by `../../07-the-sleeping-garden/prepare_assets.py`; exact sources, crop boxes, prompts and validation are stored in that level folder. `metadata.json` declares all shared export paths, pivots, sizes, states and hashes. Intended reuse: Level07 and Level09.

Sun open/folded: 48×72. Moon coiled: 48×44; organic extended alternative: 112×44. Sprout before/after/new-leaf overlay: 32×32. Pot symbols: 16×16. Stable root bridge missing/off/on/held: 48×32. Moon pot convenience composites: 128×64. Plant assets use bottom-center pivots; symbols/spans use centered pivots. Place symbols independently on pots when composed.

Only Nhinh's lantern changes plant state after reservoir light is covered. Lumo does not activate flowers or retract roots. A held root span is temporarily occupied safety geometry, not a permanent mechanical latch. Full darkness deployment can be restored by turning the lantern off. Runtime safety and restore behavior remain NOT_RUN. No engine keys have been assigned.
