## Integration traps

1. **The runtime art list is a partial whitelist, not an asset-map loader.** `CampaignArt.ts` globs all L01/L02 sprites but only selected L03 files and selected scenic/state files for L04–L10. Many mapped modules and all shared mechanisms/garden/Shadow are invisible to `getLevelArtKey` until explicitly added. The handoff also states these packages are offline art and not runtime manifests.
2. **No asset map proves navigation or collision.** The clean bases are 640×360 scenic backgrounds and explicitly are not collision maps. Build walk polygons, water/cliff/door blockers and bridge state colliders from scenario routes; align their surface with the artwork. L04 creek, L05 intake/stairs, L06 perimeter, L07 canal/bypass, L08 steps/columns, L09 walls/loop, L10 roots each have misleading baked solid silhouettes if left decorative without blockers.
3. **Background pixels can duplicate runtime props.** L05’s base already contains pipes, intake and stair; L06 has pipes/doorways/architectural rails; L07 has lamps, paths and bridge crossings; L08 has doorway/columns; L09 has a giant wheel/door. Place only state overlays that do not double these features, or explicitly mask/cover the baked feature for a changing state. Garden bottom crossing is called out in its README as needing a canal patch to prevent a false bypass.
4. **Use metadata pivots as floor anchors, not image centers by habit.** Most small Level04–09 symbols use center pivots; L01/L02 props use bottom-center. L08 statues use normalized y≈0.7955; Level10 scenic patches use bottom-center and contain retained backdrop pixels. Apply exact map anchors/size before depth sorting; otherwise feet float, posts sink or props overdraw actors.
5. **Do not bake instructional UI into room art or show scene-study captions.** Package notes identify captions/labels as review-only and route text / exact dialogue as runtime content; L03 requires notebook/order labels in UI. Keep scene previews and contact sheets out of production. Verify any full-screen baked state layer (especially L08 Shadow notch and L10 root/channel layers) is intended for that room/state and isn’t stacked with its equivalent runtime rendering.
6. **L09 clean-base metadata/key mismatch.** Runtime asks for `observatory-clean-base`; map metadata lists `observatory-base`. Both files exist and CampaignArt directly includes clean-base, but the asset handoff map does not attest its pivot/hash. Confirm the intended clean version and add metadata before treating it as validated.

## Recommendation

Reuse the current PNGs and source-backed composites. Establish a per-level scene plan from each scenario with (a) floor lane and entry/exit anchor, (b) explicit obstacle/collider masks for baked stone/water/tree silhouettes, (c) back/mid/front depth bands, and (d) interaction footprints based on the normalized asset pivots. Add all selected paths to runtime registration from the handoff metadata; prefer existing modular state art to redrawing. Do not use preview montage/caption PNGs as live scenes.
