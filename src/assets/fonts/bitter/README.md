# Bitter

Unmodified full-character-set variable font from Google Fonts (includes Vietnamese), by Sol Matas / The Bitter Project Authors.

- Source: https://github.com/google/fonts/tree/main/ofl/bitter
- Font: https://raw.githubusercontent.com/google/fonts/main/ofl/bitter/Bitter%5Bwght%5D.ttf
- License: SIL Open Font License 1.1, included in OFL.txt.

The menu loads this local font at weight 500 (Medium). Vite embeds it in the single-file production build; no external font service is used at runtime.
